# Examples

---

### To learn how to use this package in detail please use these example notebooks. 

### They're grouped by type of mesh used: triangular or regular. 

### There are three model which output is directly supported: FESOM, NEMO and ICON. 

### Reduced Gaussian grids

[`reduced_gaussian_grid_example.ipynb`](reduced_gaussian_grid_example.ipynb) filters ERA5 on ECMWF's octahedral **O96** and classical **N320** reduced Gaussian grids, using public data read over HTTPS (ECMWF Anemoi ERA5 and ARCO-ERA5).
